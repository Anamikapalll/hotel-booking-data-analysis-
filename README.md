# 🏨 Hotel Booking Data Analysis

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of hotel booking data to understand booking patterns, customer behavior, cancellation trends, and revenue-related factors.

Using Python's data analysis and visualization libraries, I explored the dataset to uncover insights that can help hotels understand their booking performance and make better business decisions.

## 🎯 Objectives

- Analyze hotel booking patterns and trends.
- Understand booking cancellations and their impact.
- Explore Average Daily Rate (ADR) trends.
- Compare canceled and non-canceled bookings.
- Identify factors influencing booking cancellations.
- Extract meaningful insights through data visualization.

## 🚀 How to Run This Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/hotel-booking-data-analysis.git
   ```

2. Navigate to the project folder:

   ```bash
   cd hotel-booking-data-analysis
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `hotel_booking_analysis.ipynb` and run the notebook cells.
